# Changelog

All notable changes are documented here. The project follows Keep a Changelog conventions before its first tagged release.

## Unreleased

### Changed

- Aligned the frontend with the published `/api/v1` backend contract.
- Added exact integer base-unit conversion and abortable, stale-safe quotes.
- Made pools, markets, portfolio, and analytics truthful about their verified data sources and unavailable data.
- Guarded swap signing behind executable, fresh, simulated prepared transactions and direct Stellar RPC submission.
- Improved mobile navigation semantics, wallet refresh behavior, and token-dialog keyboard handling.

### Documentation

- Added audit, architecture, setup, wallet, backend, testing, contribution, security, attribution, and status documentation.
